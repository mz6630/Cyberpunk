# NIGHT CITY : JACK IN

사이버펑크 2077 · 엣지러너스 세계관을 배경으로 한 인터랙티브 웹사이트 (비상업 수업용 팬 작품)

## 인트로
`intro.mp4`(19초)의 연출을 캔버스로 재현했습니다.

| 시간 | 연출 |
|---|---|
| 0.00 – 0.30 | 검은 화면 + 흩어지는 글리치 라인 |
| 0.30 – 0.42 | 가로로 늘어난 노란 잔상 |
| 0.42 – 1.25 | 로고가 시안/노랑 조각으로 찢어지며 등장 → 안정 |
| 1.25 – 9.95 | 로고 유지 (가끔 미세 글리치) |
| 9.95 – 10.90 | 시안 플래시 후 조각나며 사라짐 |
| 10.90 – 19.00 | 붉은 노이즈 배경 → 메인으로 전환 |

- 클릭 / Enter / Space / Esc: 퇴장 연출로 건너뛰기
- 시스템의 '동작 줄이기' 설정 시 글리치 없이 페이드로 재생

### 로고 넣기
투명 배경 PNG 로고를 `assets/logo.png` 로 넣으면 자동으로 적용됩니다.
파일이 없으면 임시 워드마크(NIGHT CITY)로 재생됩니다.

## 구조
```
index.html
css/intro.css
js/intro.js      ← 타이밍(T)·로고 크기 조절
assets/logo.png  ← 직접 추가
```
