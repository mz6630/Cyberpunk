# NIGHT CITY : JACK IN

사이버펑크 2077 · 엣지러너스 세계관을 배경으로 한 인터랙티브 웹사이트 (비상업 수업용 팬 작품)

## 인트로
`intro.mp4`(19초)를 프레임 단위로 분석해 캔버스로 재현했습니다.

| 시간 | 연출 |
|---|---|
| 0.00 – 0.33 | 검은 화면 → 붉은 배경이 켜짐, 상단 노란 섬광 라인 |
| 0.33 – 0.47 | 가로로 늘어난 노란 잔상 → 흰색/시안 잔상 |
| 0.47 – 1.50 | 로고가 시안/노랑 조각으로 찢어지며 형성 → 안정 |
| 1.20 – 9.97 | 로고가 천천히 줌아웃 (약 17%), 3.9 / 4.3 / 8.0초에 미세 글리치 |
| 9.97 – 10.25 | 시안 플래시 |
| 10.25 – 10.93 | 조각나며 흩어지고 배경이 꺼짐 |
| 10.93 – 11.50 | 암전 후 붉은 노이즈 배경이 다시 켜짐 |
| 11.65 – | **칩 스테이지** (아래) |

### 칩 스테이지
붉은 화면에서 칩(`assets/chip.png`)을 끌어 왼쪽 **NEURAL PORT**에 꽂으면 메인으로 넘어갑니다.
키보드는 Enter / Space로 바로 꽂을 수 있습니다.

1. 칩이 포트에 미끄러져 들어가 딸깍 — 포트가 카프리 색으로 바뀜
2. **카프리 색 전기 스파크**가 포트에서 뻗어 나가 화면 전체를 덮음
   (마젠타 `#f9034a` · 형광 연두 `#12f870` · 보라 외곽선 `#8f32bd` · 흰 반짝이,
   카프리 머리카락처럼 뾰족한 조각 포함)
3. **정전**: 모든 화면과 소리가 한 번에 꺼짐 → 잠깐의 어둠 속 마지막 작은 스파크
4. 메인 화면이 나타남

'동작 줄이기' 설정에서는 화면 흔들림이 없고 스파크 양이 줄어듭니다.

- 페이지가 열리면 바로 재생되고, 효과음도 자동 재생을 시도합니다.
  브라우저가 자동 재생을 막으면 따로 표시 없이 **첫 클릭(또는 키 입력)부터 그 시점의 소리가 이어집니다.**
- 클릭 / Enter / Space / Esc: 퇴장 연출로 건너뛰기 (소리가 켜진 뒤)
- 오른쪽 위 `SOUND ON / OFF`로 음소거 (설정은 브라우저에 기억됨)
- 시스템의 '동작 줄이기' 설정 시 글리치 없이 페이드로 재생

### 효과음
`js/sfx.js`에서 Web Audio로 직접 합성합니다 (음원 파일 없음). 타임라인은 `timeline()` 안에서 조절합니다.
소리 재료는 모두 전기 계열입니다: 스파크, 지지직 합선, 아크 방전, 변압기 험, 네온 버즈, 릴레이, 데이터 잡음.
각 소리의 강약 곡선은 화면 연출(intro.js의 T, 글리치 강도)과 같게 맞췄습니다.

| 시간 | 화면 | 소리 |
|---|---|---|
| 0.00 – 0.33 | 배경이 켜짐 | 전원이 올라오는 스웰 + 라이저 |
| 0.10 – 0.33 | 상단 노란 라인 → 글리치 라인 | 스파크 + 오른쪽으로 지나가는 '지익' → 지지직 |
| 0.33 – 0.47 | 가로 잔상 → 흰색 잔상 | 왼→오 휩쓸림 + 저음 → 밝은 전기 터짐 |
| 0.47 – 0.77 | 로고 형성 | 아크 방전 (화면 글리치와 같이 약해짐) |
| 0.77 – 1.50 | 로고 고정 → 안정 | 임팩트 + 전기 충격 → 잦아드는 지지직 |
| 1.0 – 10.85 | 로고 유지 | 변압기 험 + 네온 버즈, 3.9 / 4.3 / 8.0초 짧은 합선 |
| 9.97 – 10.77 | 시안 플래시 → 흩어짐 | 치솟는 아크 → 점점 거세지는 아크 |
| 10.77 – 11.00 | 배경 꺼짐 → 암전 | 험이 함께 꺼짐 → 정적 |
| 11.00 – 11.50 | 붉은 배경 재점등 | 릴레이 딸깍 + 형광등 깜빡임 |
| 11.50 – | 칩 대기 | 낮은 험 + 데이터 잡음 (칩을 꽂을 때까지 계속) |
| 칩 삽입 | 칩이 들어감 | 미끄러짐 + 딸깍 + 핸드셰이크 데이터음 |
| 스파크 | 카프리 스파크가 화면을 덮음 | 점점 커지는 아크 폭풍, 큰 번개마다 방전음 |
| 정전 | 검은 화면 | 모든 소리 차단 + '툭' → 정적 속 작은 스파크 |

> 발표 때 클릭 없이 처음부터 소리를 내려면 크롬을 자동 재생 허용 옵션으로 실행하세요.
> Windows: `chrome.exe --autoplay-policy=no-user-gesture-required`
> macOS: `open -a "Google Chrome" --args --autoplay-policy=no-user-gesture-required`
> (크롬이 완전히 종료된 상태에서 실행해야 적용됩니다)

### 로고
- `assets/logo.png`: 영상에서 추출한 'Cyberpunk' 글자 (투명 배경, 2077은 지움)
- 아래 줄 `WEBSITE`는 `js/intro.js`의 `SUB` 설정으로 캔버스에 그립니다.
  폰트는 원본 2077 숫자와 가장 비슷한 **Barlow Condensed SemiBold** (Google Fonts),
  색·크기·회로선 위치는 원본을 실측한 값입니다. `SUB.text`만 바꾸면 문구가 바뀝니다.
